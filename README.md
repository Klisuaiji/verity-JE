# Verity™ JE 移植（fork）

> **分支说明**：本分支（`fork`）为 **移植仓库**，用于存放将 Verity™ JE 反编译 / 移植到不同模组加载器（Forge、NeoForge）的**最初版本源码**。

## 简介

这是 Verity™ 模组移植工作的最初版本。本仓库按模组加载器与模组版本分类，存放对应版本的源码 / 反编译产物，供学习与移植参考。

## 目录结构

| 目录 | 模组加载器 | 模组版本 | 说明 |
| --- | --- | --- | --- |
| `forge-6.0.0-beta8/` | Forge | 6.0.0-beta8 | 移植的最初版本 |
| `forge-5.7.4/` | Forge | 5.7.4 | Forge 移植版本 |
| `neoforge-3.7.4/` | NeoForge | 3.7.4 | NeoForge 移植版本 |
| `skill/` | - | - | 预留目录（暂为空） |

## 通道说明

- `beta` 分支：Beta 通道，包含最新开发与测试版本内容。
- `release` 分支：正式发行通道，包含经过验证的正式发布版本。
- `fork` 分支：移植的最初版本源码归档。
